# 환자용 글 문체

2026-11-08 적용. 통증·다이어트·미용·기능성 소화불량 대표 질문 12편과 관련 글 3편, 연구노트 6편의 문장을 정리했다.

- 첫 문장에서 질문에 답한다. 도입에서 글의 구성이나 작성 의도를 설명하지 않는다.
- 치료에서 무엇을 확인하고 어떻게 경과를 판단하는지 구체적으로 쓴다.
- 같은 주제를 지역명만 바꿔 반복하지 않는다. 본문과 FAQ도 질문에 필요한 설명만 남긴다.
- “확인되지 않았습니다”로 끝내는 대신 연구 대상·관찰 기간·측정 항목을 밝힌다. 유의하지 않은 차이와 빠진 안전성 자료는 사실대로 설명한다.
- 부작용, 복용 주의와 응급 진료가 필요한 신호는 짧고 분명하게 유지한다.
- 효과를 새로 단정하거나 원내 치료 경험·검토자·실적을 만들어 넣지 않는다.
- 가격은 구매 단위와 실제 결제액부터 쓰고, 환산액은 따로 구분한다.

자동 연구노트의 초안과 수정 단계에 같은 기준을 적용한다. 문체 개선을 위해 근거 확인·독립 검증 절차를 생략하지 않는다. 기존 논문의 문장 수정은 `copyEdit`로 남기며, 과거 자동 검증 일시를 새 검증처럼 바꾸지 않는다.
