### 이전 주소와 별도 사이트

- [이전 아임웹 주소](https://ilsanhan.imweb.me/)는 HTTP 404이며 새 홈페이지로 가는 리디렉션이나 canonical 링크가 없다. 아임웹 측에서 이전 주소 제어권이 확인되면 새 홈페이지로 영구 이동을 설정할 수 있다. 당근에 남은 링크는 직접 새 주소로 교체하는 것이 우선이다.
- [기본 도메인](https://ilsanhan.com/)은 HTTP 308로 www 주소에 이동하고, 최종 페이지는 HTTP 200 및 자기 자신을 가리키는 canonical을 반환한다.
- [다이어트 별도 홈페이지](https://diet.ilsanhan.com/)에는 ‘6명의 실력있는 의료진’이라고 적혀 있다. 다이어트 진료에 참여하는 원장 수인지, 전체 의료진 수인지 해당 사이트 운영자가 확인할 항목이다. 전체 인원이라면 7명으로 갱신하고 현재 의료진 소개로 연결한다.
