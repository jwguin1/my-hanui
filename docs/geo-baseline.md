# GEO 진단 기준선 (회귀 탐지용)

이 문서는 **회귀 탐지 기준선**이다. 점수를 올리기 위한 목표치가 아니다.
작업 배포 후 같은 페이지를 같은 도구로 재측정해서, 기준선보다 낮아지면 즉시 보고한다.

측정은 원장이 직접 수행한다. 여기에는 **전달받은 값만** 기록한다.
에이전트가 점수를 추정하거나 채워 넣지 않는다.

## 재측정 규칙

1. 배포가 프로덕션에 반영된 것을 확인한 뒤 측정한다 (배포 직후 30~60초는 전파 중일 수 있다).
2. 기준선과 **같은 URL**, **같은 도구**로 측정한다. 대상이 바뀌면 비교가 성립하지 않는다.
3. **100 미만이면 즉시 보고.** 점수만 보고하지 말고 어느 항목이 왜 내려갔는지 특정한다.
4. 회귀가 확인되면 원인을 특정한 뒤 보고하고 지시를 기다린다.
   점수를 되돌리려고 마크업을 즉흥적으로 바꾸지 않는다.

### 회귀 감시 대상 (slug 작업)

한글 슬러그 도입은 URL 문자열을 바꾸는 작업이므로 아래가 직접적인 위험이다.

| 항목 | 왜 위험한가 |
|---|---|
| @id 식별자 부여 | canonical / og:url / JSON-LD `@id` 가 한 글자라도 갈리면 엔티티 병합 실패 |
| 이동경로(BreadcrumbList) | 마지막 항목 `item` URL 이 슬러그에서 파생됨 |
| 사이트·페이지 엔티티 | `#webpage` @id 가 슬러그 기반 |
| 구조화 데이터 서버 렌더링 | 슬러그 조회 실패 시 404 로 떨어져 JSON-LD 자체가 사라짐 |

기존 32편의 URL은 이번 작업으로 **바뀌지 않는다.** 홈 기준선 재측정으로 회귀가 잡히지 않는
영역(글 상세)은 아래 "미측정 유형" 목록으로 별도 측정한다.

## 미측정 유형 — 원장 추가 측정 대상

홈만 측정된 상태다. 아래는 홈과 **JSON-LD 구조가 다른** 페이지 유형이라
홈 점수가 100이어도 같은 점수를 보장하지 않는다.

### A. 글 상세 (Article + MedicalWebPage) — 카테고리별 1편

```
https://www.ilsanhan.com/pain/20260726-post-1
https://www.ilsanhan.com/diet/20260726-post-2
https://www.ilsanhan.com/autonomic/20260728-post-1
https://www.ilsanhan.com/skin/20260426-post-5
```

각 카테고리의 최신 발행 글이다. 홈에 없는 노드(`Article`, `Physician` 스텁)가 들어가고
`@type` 이 `MedicalWebPage` 단독(FAQ 없음)이라 유형별 기대 엔티티 판정이 홈과 다르게 나온다.

### B. 카테고리 목록 (CollectionPage + ItemList)

```
https://www.ilsanhan.com/pain
https://www.ilsanhan.com/diet
https://www.ilsanhan.com/autonomic
https://www.ilsanhan.com/skin
```

`ItemList` + `Article` 스텁 다수가 들어가는 유일한 유형이다.
`/pain` `/diet` `/skin` 은 `verify-carousel` 이 동결한 캐러셀 타깃이기도 하므로
회귀 시 검색 순위에 직접 영향이 간다 — 4개 중 우선순위가 가장 높다.

### C. accident (MedicalWebPage + FAQPage)

```
https://www.ilsanhan.com/accident
```

`/pain` 하위가 아닌 단독 최상위 진료 페이지다. 이동경로가 `홈 > 교통사고` 2단이라
다른 진료 페이지(3단)와 구조가 다르다.

### D. autonomic

```
https://www.ilsanhan.com/autonomic/care
```

진료 상세 페이지 중 유일하게 글 1편짜리 카테고리를 부모로 둔다.
`/autonomic`(B)과 짝으로 측정하면 목록↔상세 연결성 판정을 볼 수 있다.

### 참고: 위 4개 외에 아직 유형이 확인되지 않은 페이지

측정 요청 목록에는 넣지 않는다. 위 A~D 결과를 보고 필요하면 그때 추가한다.

- `/internal/dyspepsia` — 이동경로가 평탄화된 유일한 페이지(`홈 > 소화불량`)
- `/about`(AboutPage) · `/contact`(ContactPage) — 홈과 다른 `@type`
- `/doctor` — `Physician` 정식 노드 6개가 유일하게 실리는 페이지
- `/blog` `/column` `/media` `/treatment`
