# 통증·다이어트·미용·기능성 소화불량 운영

적용일: 2026-11-08

- 첫 화면 추천 질문은 네 분야를 하나씩 안내한다. 기존 8개 진료 메뉴는 유지한다.
- `/blog` 첫 부분의 네 카드에서 분야별 대표 질문 3개를 읽는다. 전체 글 검색도 유지한다.
- `src/lib/focus-guides.ts`가 대표 질문·진료 안내·연구노트 연결의 기준이다. 발행된 글만 연결한다.
- 소화불량 글 3편은 NIDDK 환자 안내를 출처로 작성했다. 실제 의료진 검토자로 표시하지 않는다.
- 새 질문은 기존 글과 검색 의도가 겹치는지 먼저 확인한다. 같은 답을 지역명만 바꿔 늘리지 않는다.

## 연구노트

- 월·수·금 오전 9시, 통증 → 다이어트 → 미용 → 기능성 소화불량 순으로 순환한다. 4주에 분야별 3회다.
- 이미 예약된 글은 날짜를 유지한다. 기존 예약과 새 분류가 같은 날짜에 겹치면 새 글을 중복 발행하지 않는다.
- 환자 질문을 먼저 고른 뒤 해당 질문의 검색 결과 안에서 인용수·연구 유형·연령을 비교한다. 최근 10년, 원문·라이선스·근거 검증과 독립 검토, 실행별 비용 상한은 유지한다.
- 성공한 글의 `editorialQuestion`에 질문 ID를 기록해 아직 다루지 않은 질문을 우선한다.
- 그림은 검증에만 사용하고 게시글에는 첨부하지 않는다.
- 기존 `korean` 주소는 유지한다. 제목에서 기능성 소화불량이 확인되는 기존 논문은 소화불량 목록에서도 보여준다.
- 공개 논문이 없는 분야 목록은 진료 질문을 보여주고, 논문이 공개될 때까지 noindex 처리한다.

- 실제 예약과 내원 여부는 데스크 집계로 별도 확인한다. 이 자료를 Analytics에 보내지 않는다.

- `/site-analytics`에서 수집 범위와 브라우저별 사용 중지 기능을 제공한다.
